## Projects

### 1. SSH Brute-Force Investigation
Investigated a Linux server log (auth.log) to find out whether the server
was attacked, who did it, and what they did after getting in.

**Key findings:** 612 failed logins from one IP, a successful break-in,
stolen password hashes, a hidden admin backdoor, and a suspected malicious
download, all completed in under 3 minutes.

**Skills:** Linux command line, log analysis, grep, incident timeline,
Indicators of Compromise (IOCs), incident response (contain, eradicate,
recover)
